## 3. 三条硬规则

1. 无 LIVE 绑定不算任务。任务必须声明可启动的本地应用、窗口选择、运行后可读的应用记录面。缺少这三样的任务只能用于 runner 自检。
2. 无行为探针不算变体。快照目录存在只证明面被冻结，不证明行为已实现。任何变体在跑任务前必须先通过 E1.5 行为探针，否则状态为 `NOT_RUNNABLE`，不产出 0% 或 100% 的结果。
3. 无预注册端点不裁决。每个阶段开跑前冻结端点表（主端点、N、MDE、否决线、停止条件）；开跑后修改规则会使本轮数据作废。

变体差异只由 `versions/surface-<id>/` 快照数据表达；代码只读快照 dispatch，不读变体 id。

## 4. 执行路径：E0.5 LIVE 适配层

### 4.1 LIVE 适配器

- 新增 `harness/run.py live` 或等价入口，契约沿用 `subagent-prepare` / `subagent-collect` 的“模型侧只读 surface 快照”约定。
- 任务数据只带启动规格：`screen`、`launch{exe,args}`、`window_title`、`reset=restart`、`teardown=kill`。适配器按规格启动、按标题选窗、任务结束清场，不包含应用分支。
- 启动前 `somnus doctor` 必须报告子会话 live；不满足时 `BLOCKED_CHILD_SESSION`，不尝试主桌面。
- 每个任务使用独立进程与窗口；窗口集合在启动前与断言后各取一次快照，用于确认没有多开、残留或越界窗口。
- 构建前置：`dotnet build apps/scenario-suite`；五屏各启动一次并 `observe` 到记录面（store 的 cart、form 的 records、tree 的状态行等）。

出口：live smoke 3/3（同一屏连续三次启动、操作、断言、清场）；清场后窗口集合与启动前一致；泄露扫描为 0；`selfcheck` 增加 live 项且全绿。

### 4.2 断言会话

- 运行后新开一个会话，`observe` 目标窗口，按语义查询读取应用自己的记录面（状态行、cart 列表、form 记录列表、输入框 value）。
- 语义查询只允许 `{role, name, in?}`，不允许 AutomationId、fixture 选择器、索引或窗口枚举序号。
- 断言原语限定为 `read_text`、`read_value`、`child_names`（多重集）、`exists`。状态类断言读取状态行文本。
- 断言读取完成后再清场；断言产物记录查询、命中行与判定，不落原始整树。

出口：同一任务连续 3 次，断言读到的记录面文本与参考解一致；移除断言会话时任务必须失败。

### 4.3 清场与隔离

- 每任务重启应用；断言后 kill；窗口与进程集合前后比对。
- 子会话掉线：本次标记 `INFRA_DROPPED`，最多重跑 1 次；仍失败则停批，不切换主桌面。
- 剪贴板与前台窗口按 v1 §5.2 恢复；不跨任务复用 ref。

出口：连续 12 次运行无跨任务状态残留；`INFRA_DROPPED` 为 0；泄露为 0。

## 7. 难度与端点

### 7.1 天花板协议

v1 测得 S0 为 100%，继续加深会使弱变体同时失效。v3 按 S0 成功率分支处理：

| S0 成功率 | 处理 |
| --- | --- |
| 60%–95% | 正常；成功率可作采纳端点 |
| ≥95% | 天花板；成功率只作非劣性门槛，采纳只来自效率端点 |
| <60% | 装置或环境问题；停止，禁止靠放松断言压难度 |

天花板状态在报告中显式记录为 `CEILINGED`。

### 7.2 Headroom 预检

每类先在 S0 上测 3 次，满足任一条才算有头寸，否则只作诊断：

- 工具回合 ≥ 参考解 + 1 的次数 ≥30%；
- 任务 token 的 CV ≥0.10；
- 无效调用率 >0。

预检结果冻结到 `scratch/blackbox-toolset/prereg/v3-headroom.json`；没有头寸的类不能成为效率主端点。

允许更换的难度杠杆：

1. 接受天花板加效率端点（默认）。
2. 降低 `max_steps`（12 → 9），只作校准，不用于裁决。
3. 更换同族更弱档位的被测主体，不改任务与变体。
4. 环境扰动（更小视口、更慢 settle），需先验证断言稳定。
5. 继续加深同类任务：禁止。

### 7.3 端点

| 端点 | 定义 | 用途 |
| --- | --- | --- |
| P1 成功率 | 断言全通过的任务运行占比 | 门槛或否决 |
| P2 语义/调用回合 | 每任务工具调用数；run 脚本内步骤另计语义步 | 主效率端点 |
| P3 token | 注入 + 完成 + 工具返回三分账本 | 主效率端点 |
| P4 无效调用率 | `ERR *` / 全部调用 | S0 > 0 时使用 |
| P5 墙钟 | 诊断 | 不裁决 |

变体主端点预注册：S3a/S3b → P2；S1 → observe 回合（P2 子集）；S2 → P1 非劣性加参数误用；S5a/S5b → offscreen 类的 P2。

## 8. 判定规则

预注册：每阶段、每变体一份端点表（主端点、类清单、N、MDE、否决线、停止条件），冻结 hash 后开跑，存 `scratch/blackbox-toolset/prereg/`。不做中途看数。

成功端点：

- 非天花板：采纳要求 `Δsuccess ≥ +15pp` 且配对 95% CI 下界 > 0（与 N=36 的 MDE 对齐）；`+5pp` 至 `+15pp` 记 `PENDING`，进入 confirm。
- 天花板：成功率只作非劣性门槛；点估计下降 ≤5pp，且 95% 上界 ≤10pp；采纳不引用成功率。
- 否决：汇总成功率下降 ≥10pp 且 CI 下界 > 0；或某一类下降 ≥20pp 且在 ≥2/3 实例中出现。单实例单次失败不构成否决。

效率端点：

| 端点 | 采纳阈值 |
| --- | --- |
| P2 回合 | 配对中位下降 ≥15%，且 bootstrap 95% 下界 > 0；或中位少 ≥1 回合 |
| P3 token | 配对中位下降 ≥10%，且下界 > 0；稳态每轮新增 ≤150 token |
| P4 无效调用 | S0 > 0 时，相对下降 ≥30% 且绝对下降 ≥1pp；S0=0 时只作护栏 |

特则：

- S1：主端点为 observe 回合下降 ≥25%（配对，CI 下界 > 0）；护栏为 K8 类 token 上升 ≤25%。护栏被突破时只能写“条件采纳（仅 K3/K7 类）”。
- S2：主判据为成功非劣性与参数误用。基线误用为 0 时用绝对阈值（≥2 次/10 任务或 ≥15%）；基线 >0 时用 2 倍相对阈值。
- S5a/S5b：offscreen 类回合下降 ≥15%，成功率不降；新增工具 schema 与描述成本单独列出。两者都通过时，优先 token 中性且无解析错误的一种。
- S3a/S3b：回合下降 ≥15% 或 token 下降 ≥10%；不使用方差下降作为端点。
- S4：本轮无主端点。

小样本与 MDE：

| N（配对观测） | 二值端点近似 MDE | 连续端点近似 MDE |
| --- | --- | --- |
| 12（screening） | 约 25pp | 约 1.0 回合 |
| 36（decide） | 约 12–15pp | 约 0.5 回合 |
| 60（confirm） | 约 8–10pp | 约 0.4 回合 |

观测效应小于 MDE 时只写 `PENDING` 或 `NOT_DISTINGUISHABLE`。以任务实例为重采样单位，配对 bootstrap 10k 次；多端点只裁决预注册主端点。

停止条件：

| 条件 | 动作 |
| --- | --- |
| 泄露扫描 >0 | 立即停止该条件，本轮作废 |
| surface 或 snapshot hash 漂移 | 停止并重新冻结 |
| 子会话掉线、UIA 异常、应用启动失败 | `INFRA`，重跑 ≤1，仍失败停批 |
| oracle 失败或断言不稳定 | `TASK_INVALID`，修复并重跑参考解 |
| S0 LIVE 成功率 <60% | 停止，检查装置与环境 |
| 开跑后修改规则 | 本轮数据全部作废 |

## 13. 风险与护栏

| 风险 | 缓解 |
| --- | --- |
| LIVE 应用跨任务残留或多开 | 每任务重启、前后窗口快照、kill 后确认集合一致 |
| 断言会话污染被测状态 | 断言另开会话，只读记录面，读后清场 |
| 子会话掉线 | `INFRA_DROPPED`，重跑 ≤1，停批 |
| 未实现变体产出结果 | E1.5 探针门；`NOT_RUNNABLE` 不进入裁决 |
| 天花板被误读为“无差异即采纳” | 采纳只来自效率端点；成功只作非劣性门槛 |
| 小样本过判 | 预注册 MDE；低于 MDE 只写 `PENDING` |
| 为通过而改任务或断言 | 任务变更先重跑参考解并重新冻结；数据事后不改规则 |
| 云端越界 | 白名单、前后快照、泄露扫描一票否决 |
| 实测数据堆积 | `runs-v3` 只保留每轮 JSON 摘要与失败轮 transcript；超过 50MB 先归档 |
| 变体靠 id 分支 | 代码只读快照 dispatch；新增变体只加目录 |

## 14. 术语

| 术语 | 含义 |
| --- | --- |
| `LIVE_OK` | 有真实屏、参考解 3/3、断言稳定 |
| `LIVE_CONDITIONAL` | 有真实屏，但断言或 oracle 需按 LIVE 语义改写 |
| `MOCK_ONLY` | 只在 mock 上存在，不作为黑盒证据 |
| `CEILINGED` | S0 成功率 ≥95%，本轮不以成功率为采纳端点 |
| `NOT_RUNNABLE` | 变体缺少运行时行为或探针未通过 |
| `PENDING` | 观测效应低于预注册 MDE，需要 confirm 或放弃 |
